### 技术细节

#### FieldDefinition 接口关键属性
- `isMain`: 是否主表字段（1=主表，0=明细表）
- `detailTable`: 所属明细表索引（0/null=主表，1=明细表1，2=明细表2...）
- `fieldHtmlType`: 字段HTML类型（1=文本，2=浏览按钮，3=选择框，4=附件，5=特殊字段，6=复选框，8=下拉框，9=树形选择）
- `fieldType`: 字段详细类型（根据 fieldHtmlType 组合确定具体类型）
- `fieldName`: 数据库字段名
- `fieldLabel`: 字段显示名称

#### 字段图标映射
根据 `fieldHtmlType` 和 `fieldType` 显示不同的图标：
- 文本字段：FontSizeOutlined（单行）/ EditOutlined（多行）
- 浏览按钮：TableOutlined
- 选择框/下拉框：DownOutlined
- 附件：PaperClipOutlined
- 日期/时间：CalendarOutlined
- 复选框：CheckSquareOutlined
- 树形选择：UnorderedListOutlined

## UniverExcelGrid 初始化 bug 修复

### 问题1: `containerRef.current 为空`
**现象**: 控制台报错 `[Univer Init] containerRef.current 为空`
**根因**: 回调 ref 的设置时机和 `useEffect` 执行顺序不可靠，导致初始化代码运行时 `containerRef.current` 仍为 `null`。
**修复**: 将单次 `requestAnimationFrame` 改为**递归 RAF**（`attemptInit` 函数），持续等待 `containerRef.current` 就绪后再开始初始化。

### 问题2: 一直显示"正在加载 Excel 表格..."
**现象**: 页面永远卡在加载状态，无法完成初始化。
**根因**: 当 `!initialized` 时，组件用条件渲染显示 `<Spin>`，而**包含 `containerRef` 的 div 根本没有被渲染**，导致 `containerRef.current` 永远为 `null`，递归 RAF 永远等不到 container。
**修复**: 
- 移除条件渲染，改为**始终渲染 container div**
- 加载/错误状态用**遮罩层**（`position: absolute`）叠加显示在 container 上方
- `Card` 的 `styles.body` 设置 `position: 'relative'` 作为遮罩层的定位锚点

**文件**: `ant-design-pro/src/pages/FormMode/ExcelDesign/components/UniverExcelGrid.tsx`

## range.setValue 修复（Facade API）

### 问题: `range.setValue is not a function`
**现象**: 拖放字段到单元格时报错：`UniverExcelGrid.tsx:354 设置单元格字段失败: TypeError: range.setValue is not a function`

**根因**: 代码使用底层 `Worksheet.getRange()` 返回的是底层 `Range` 对象，底层 `Range` **没有** `setValue()` 和 `setNote()` 方法。这些方法只存在于 **Facade API** 的 `FRange` 类中。

**修复**: 将整个初始化从底层 API (`Univer`) 改为 Facade API (`FUniver`):
1. 添加导入: `import { FUniver } from '@univerjs/core/facade';`
2. 使用 `new FUniver({...})` 替代 `new Univer({...})`
3. 使用 `fUniver.createWorkbook({...})` 替代 `univer.createUnit(UniverInstanceType.UNIVER_SHEET, {...})`，返回 `FWorkbook`
4. `FWorkbook.getActiveSheet()` 返回 `FWorksheet`
5. `FWorksheet.getRange(row, col)` 返回 `FRange`，有 `setValue()`、`setNote()`、`getValue()`、`getNote()`、`setStyle()` 方法
6. 更新所有相关函数使用 Facade API: `setCellField`、`getCellFieldMeta`、`loadLayoutData`、`saveLayoutData`、`handleFieldDrop`、`useDrop` 回调
7. 更新 ref: `fUniverRef` (FUniver)、`fWorkbookRef` (FWorkbook)
8. 清理未使用的导入 (`Univer`、`UniverInstanceType`)

**文件**: `ant-design-pro/src/pages/FormMode/ExcelDesign/components/UniverExcelGrid.tsx`
