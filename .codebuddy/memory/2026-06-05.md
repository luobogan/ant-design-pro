## Excel 设计器字段放置功能修复

### 问题描述
用户在使用 Excel 设计器时遇到两个错误：
1. 选中字段时显示 "已选中字段 'undefined'"
2. 放置字段时报错：`range.setNote is not a function` 和 `sheet.getRowCount is not a function`

### 根本原因
1. **字段属性判断错误**：`ExcelDesign.tsx` 的 `handleFieldSelect` 函数中，`isFormField` 判断逻辑错误地使用了 `field.fieldId`（应为 `field.id`，因为 `FieldDefinition` 的 ID 属性是 `id`）
2. **Univer API 使用错误**：
   - FRange 没有 `setNote()`/`getNote()` 方法
   - FWorksheet 没有 `getRowCount()`/`getColumnCount()` 方法，需要用 `getSnapshot()` 获取

### 修复方案

#### 1. ExcelDesign.tsx (第 114-151 行)
- ✅ 修正 `isFormField` 判断逻辑
- ✅ 为 `fieldLabel`、`fieldName` 添加默认值
- ✅ 修复 `id` 属性获取逻辑（`FieldDefinition` 使用 `id` 而非 `fieldId`）

#### 2. UniverExcelGrid.tsx
- ✅ 新增 `cellFieldMetaMap` (useRef) 存储字段元数据到内存
- ✅ 移除所有 `range.setNote()` / `range.getNote()` 调用
- ✅ 修复 `saveLayoutData` 中的 `getRowCount()` → 改用 `sheet.getSnapshot().rowCount`
- ✅ 修复 `saveLayoutData` 中的 `getColumnCount()` → 改用 `sheet.getSnapshot().columnCount`
- ✅ 新增 `getCellFieldMeta()` 函数从内存 Map 读取字段元数据
- ✅ 删除重复的 `getCellFieldMeta` 函数定义
