# 2026-06-09 工作记录

## SpringBlade 表单建模模块 Bug 修复

### 1. 明细表字段拖动没反应（已修复）
- 根因：`DragableTableRow` 组件 `useSortable` 的 id 固定为 `field-${index}`，但明细表字段的 id 应该是 `detail-field-${index}`，导致 dnd-kit 无法匹配，`onDragEnd` 永远不会触发。
- 修复：`DragableTableRowProps` 新增可选参数 `idPrefix`（默认 `'field'`），`useSortable` 的 id 改为 `\`${idPrefix}-${index}\``。明细表 `components.body.row` 中传递 `idPrefix="detail-field"`。

### 2. 加载后第一个明细表 Tab 要自动选中（已修复）
- 修复：`setDetailTables` 后添加 `setActiveDetailTab(newDetailTables[0]?.key || '')`。

### 3. 字段重复显示 + 明细表数量丢失（已修复）
- 根因1：`useEffect` 在 React 18 StrictMode 下会执行两次，每次都 `setFields([...defaultSystemFields, ...mainFields])`，导致系统字段重复追加。
- 根因2：`allDetailTableIndices` 记录所有出现过的明细表索引（包括只有系统字段的明细表），但合并时遗漏了只有系统字段的明细表。
- 修复：使用 `AbortController` 模式防止 effect 多次执行；合并所有明细表索引后统一生成 `newDetailTables`。

### 4. 输入框焦点丢失（已修复）
- 根因：`onChange` 每次按键都触发父组件状态更新，导致重新渲染和焦点丢失。
- 修复：`EditableCell` 使用本地状态管理输入值，只在失焦（`onBlur`）或回车（`onKeyDown`）时才更新父组件状态。

### 5. 字段编码/名称输入内容无法输入（已修复）
- 根因：`@dnd-kit` 的拖拽事件干扰了输入框的点击。
- 修复：给 `Input` 添加 `onMouseDownCapture={e => e.stopPropagation()}` 阻止拖拽事件干扰。

### 6. 删除字段后保存，已删除字段仍能被查询获取的 Bug（后端修复）
- 根因1：`getByFormId` 查询未过滤逻辑删除的字段。
- 根因2：`deleteFieldWithColumn` 是物理删除，数据不可恢复。
- 根因3：实体类缺少 `isDeleted` 和 `status` 字段。
- 修复：
  - 实体类（`FieldDefinition.java`、`FieldExtend.java`、`FieldOption.java`）添加 `isDeleted` 和 `status` 字段。
  - Service 层：`getByFormId` 添加 `ne(isDeleted, 1)` + `ne(status, -1)` 过滤；`deleteFieldWithColumn` 改为逻辑删除（设置 `isDeleted=1, status=-1`）；新增 `@Transactional` 注解。
  - 数据库变更脚本：`doc/sql/formmode_logical_delete_migration.sql`（幂等版，可重复执行）。

### 7. 数据库列名格式问题（已修复 ✅）
- 问题：`@TableField` 注解值与实际数据库列名格式不一致，导致 `Unknown column` 错误。
- 根因：数据库列名使用**驼峰格式**（camelCase），但实体类错误使用了下划线格式（snake_case）。
- 修复内容：
  - **FieldDefinition.java**：重写整个文件，所有 `@TableField` 值改为驼峰格式（`billid`、`fieldname`、`dsorder`、`textheight`、`ismand`、`fieldorder`、`isused`、`quicktype`、`impcheck`、`checkexpression`、`needlog`、`needeexcel`），例外：`tenant_id`、`is_deleted`、`status` 保持下划线格式。
  - **FieldOption.java**：`@TableField` 值从 snake_case 改为 camelCase（`fieldid`、`formid`、`optionvalue`、`optionlabel`、`listorder`、`isdefault`）。
  - **WorkflowBill.java**：`@TableField("detail_table_count")` → `@TableField("detailtablecount")`。
  - **FormLayout.java**：所有 `@TableField` 值从 snake_case 改为 camelCase（`formid`、`layoutname`、`layoutjson`、`layoutconfig`、`createtime`、`updatetime`），新增 `isDeleted` 字段。
- 验证：所有文件无 lint 错误。
