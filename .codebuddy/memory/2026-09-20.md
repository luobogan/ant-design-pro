## 排查：test1 打开 /workflow/create 报 401（已定位，未改代码——需在用户管理里改角色）

## 复现手段：自签 JWT 直接打接口（免密码，排查利器）
- 依据：`blade-gateway` 的 `JwtUtil` 用 `Keys.hmacShaKeyFor(Base64.decode(Base64.encode(signKey)))` ≈ **signKey 的原始字节**做 HS256；`signKey` 在 Nacos `blade.yaml` 的 `blade.token.sign-key`（当前 `qHJlcyzQ7YoGmHA7wZzvioTKYzYMaugG`）。
- 脚本：`node` + `crypto.createHmac('sha256', Buffer.from(signKey))`，claims 用 `TokenConstant` 的名字：`user_id / account / user_name / role_id / role_name / tenant_id / client_id / iat / exp`，请求头 `Blade-Auth: bearer <jwt>`，网关 `http://192.168.1.5:81/<服务名>/...`。
- 注意：web 登录的密码是 **SM2 加密**后提交的（`TokenUtil.decryptPassword` → `SM2Util.decrypt`），所以 curl 直接传明文密码会报 "exception decoding Hex string"（非 hex 字符时）或"用户名或密码错误"（纯数字恰好是合法 hex）。
