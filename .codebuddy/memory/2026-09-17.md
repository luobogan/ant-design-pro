- 需求：选中网关节点时也要能看到/配置其下游分支（此前网关不在 `wf_process_node`，右侧栏/出口信息都看不到分支）。
- 方案：新增 `wf_node_link.via_gateway_key` 列（迁移 `V2026.09.17_003`）；后端 `saveBpmn` 穿透网关折叠时记下"经哪个网关"。

- 同时修复：删"追加边界事件"丢宿主网关出口——后端把 BE 出线并入宿主、前端删除前 `reconnectStart` 接回。
- ⚠️ 旧数据须重新保存一次 BPMN 才会回填 `via_gateway_key`，否则网关分支仍不显示。

## 追加：点网关旁的「连线」也展示网关分支（用户反馈"网关前后、后面的线条出口信息没显示"）
- 根因：①点网关**两边的连线**时，物理线（节点→网关 / 网关→节点）在库里被折叠成逻辑出口（节点→节点），`currentLink` 匹配不到 → 右侧栏落到空态；②旧数据没有 `via_gateway_key`。
- 修复：`BpmnDesigner.selection.changed` 里，选中连线若一端是网关 → 回调 `onSelectGateway(gwKey,name,fromKeys,toKeys)`（把该连线直接归到网关名下展示其全部分支）；`fromKeys/toKeys` 用「只穿网关不越节点」BFS 采集网关的上游/下游业务节点。
- `LinkInfoPanel` 增 `gatewayFromKeys/gatewayToKeys`：优先按 `viaGatewayKey` 精确过滤，为空时兜底 `from∈上游 && to∈下游`（不依赖重新保存）。
- 改完前端无 lint 错误；仍需重启 8000 + 重编后端 + 跑迁移 `V2026.09.17_003`。

## 追加：上一轮"连线归网关"的 bug（用户复现"还是不显示"）
- ❗ 根因：连线分支里用**形状版** `isGatewayEl`（看 `.businessObject.$type`）去判断 `conn.businessObject.sourceRef/targetRef`，但 sourceRef/targetRef 是**业务对象**（直接 `. $type`），故永远判不到网关 → 落到 `onSelectLink` → 出口信息空。
- 修复：`selection.changed` 连线分支改用 `isGatewayBO`（看 `. $type`）判断 sourceRef/targetRef，命中后用其 id 经 `elementRegistry.get` 取形状再 `fireGateway`。Lint 0 错误。
- ⚠️ 经验：bpmn-js 里"形状(Shape)"带 `.businessObject`，但"连线.businessObject.sourceRef/targetRef"已是解析后的业务对象，二者判断入口不同。

## 追加：改为「点哪条线显示该线唯一一条出口信息」（用户进一步明确需求）
- 用户要：网关前后的线，每一条有它**自己唯一**的一条出口信息，不要堆出网关全部分支。
- 新逻辑：点网关相邻的连线时，用 `gwBO.id` 经 registry 取形状 → `collectNodes` 采上/下游业务节点；
  - 网关作 source（gateway→X）：唯一逻辑出口 = 上游唯一业务节点 → X；
  - 网关作 target（X→gateway）：唯一逻辑出口 = X → 下游唯一业务节点。
  - 远端须为业务节点（网关接网关不唯一定位）且 from/to 都能唯一解析 → `onSelectGateway(undefined)` + `onSelectLink(from,to)` 直接显示该条 `LinkDetail`；否则回退 `fireGateway`（全部分支概述，用于网关形状点选 / 多进多出 / 网关接网关）。
- 点「网关形状本体」仍走 `fireGateway` 显示全部分支概述。Lint 0 错误。

## 追加：点「节点→网关」入线（如 3→网关）出口信息出不来（2026-09-18 复现）
- 现象：gateway→X 出线能显示唯一分支详情，但 3→网关 入线"点不出"。
- 根因推断：`registry.get(gwBO.id)` 取网关形状在个别图里取不到（业务对象 id 与形状 id 不完全一致）→ `gwShapeEl` 为空 → 入线回退分支时 `fromKeys/toKeys` 没传 → 网关模式分支表空白。
- 修复：网关形状直接从连线两端取 `conn.source/conn.target`（`conn.source?.businessObject === gwBO` 判等），不再依赖 `registry.get(gwBO.id)`；入线无法唯一定位时稳定 `fireGateway(gwShapeEl)`（带上下游节点，分支表必有内容）。Lint 0 错误。
- 语义说明：节点→网关 入线在"一进多出"判定网关下没有"唯一"逻辑出口（它扇出到多条），故显示该网关全部分支概述（即 3 能去的出口）；gateway→X 出线才显示单条分支详情。
