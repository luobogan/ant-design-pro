### ③ UniverExcelGrid 新增 Facade API（挂到 `window.univerExcelGrid`）
- `applyRangeFormat(action, value)`：对当前选区应用样式。action = `bold/italic/underline/align/valign/bg/color/fontSize/wrap`；内部 switch 调 FRange 的 `setFontWeight/setFontStyle/setUnderline/setHorizontalAlignment/setVerticalAlignment/setBackground/setFontColor/setFontSize/setWrap`，全部 try/catch。
- `mergeSelection()` / `unmergeSelection()`：FRange `merge()` / `breakApart()`。
- `rowColOp(op)`：`insertRow/insertCol/removeRow/removeCol`，以 `getSelection()`（回退右键命中格）的行列为准，调 FWorksheet `insertRowBefore/insertColumnBefore(回退 insertColumnAfter)/deleteRow/deleteColumn`；**操作后 `setTimeout(saveLayoutData, 0)`**，因为行列结构性变更需重排字段元数据坐标并持久化。
- `getActiveRangeSafely()`：`sheetRef.current.getActiveRange()`（Facade 无选区返 null）。

**Facade 签名核对**（`univer/packages/sheets/src/facade/`）：
- `FWorksheet`: `insertRowBefore(pos)`、`insertRowAfter(pos)`、`deleteRow(pos)`、`insertColumnAfter(pos)`、`deleteColumn(pos)`、`getActiveRange()`。
- `FRange`: `setBackground(color)`、`setWrap(bool)`、`setHorizontalAlignment(alignment)`、`setFontWeight(bold|normal|null)`、`setFontStyle(italic|normal|null)`、`setFontSize(number|null)`、`merge(options?)`、`breakApart()`。

## 续53: 「模板/格式/插入/字段属性/明细表」能否集成进 Univer（结论：可以，走原生 ribbon）
**结论: 可行，且推荐走 Univer 原生 ribbon；无需重新 build univer。**
**关键依据**（已核实）:
- Univer **自带 ribbon**：`univer/packages/ui/src/services/ribbon/ribbon.service.ts`，`UniverUIPlugin` 中注册 `[IRibbonService, {useClass: DesktopRibbonService}]`（`ui/src/plugin.ts:106`）。
- **Facade 支持运行时加菜单**：`univer/packages/ui/src/facade/f-menu-builder.ts` → `univerAPI.createMenu({id,title,icon,tooltip,action})` / `createSubmenu(...)`，`.appendTo(path)` 内部 `IMenuManagerService.mergeMenu()`。`action` 可为**普通回调**（Facade 用 generateRandomId 自动注册 command 并绑定），故不必自己写命令。
- **位置常量**（`ui/src/services/menu/types.ts`）：`RibbonPosition`: `ribbon.start/insert/formulas/data/view/others`；`RibbonStartGroup`: `ribbon.start.history/format/layout/others`；`RibbonInsertGroup`: `ribbon.insert.edit/media/others`。`appendTo('ribbon.start.others')` 即嵌套 `{ribbon:{start:{others:{[id]:schema}}}}`。
- **运行时 Facade 已含 createMenu**：`ant-design-pro/src/univer-lib/ui/lib/es/facade.js` 存在 `createMenu`/`createSubmenu` → **不用改 univer 源码、不用 build**。
- Facade 实例已挂载：`window.__univerFAPI`（UniverExcelGrid 中 `FUniver.newAPI(univer)` 后暴露）。
**建议方案（混合）**:
- **格式 / 插入** → 走原生菜单项（纯命令式，无需 React 状态）：`createMenu(...).appendTo('ribbon.start.format' | 'ribbon.insert.others')`，回调里调 `window.univerExcelGrid.applyRangeFormat / rowColOp / mergeSelection`。
- **模板 / 字段属性 / 明细表** → 需要下拉、禁用态、与 React 状态联动（fieldAttr 高亮、detailTableOptions 动态），建议注册为**自定义 React 组件**（`ComponentManager.register` + 菜单项引用），或保留在外挂 `ExcelRibbon` 中。
**注意点**:
1. 菜单 `icon` 是 Univer 图标 key（需 `ComponentManager` 注册 SVG），不能直接用 antd 图标；可先省略 icon。
2. 若新增**自定义 ribbon tab**（如 ribbon.template/fieldAttr/detail），tab 标题需要 i18n（`new Univer({locales})` 处补），否则可能显示原始 key；复用现有 tab 分组可规避。
3. 明细表下拉依赖动态数据（detailTableOptions）→ 静态菜单不适合，用 `createSubmenu` 动态注册或自定义面板。
4. 原生菜单项的 disabled/hidden 需 `disabled$`/`hidden$` **Observable**（渲染层不认普通函数，见既有右键菜单踩坑）。
**待确认**: 采用「原生菜单项 + 自定义组件」混合方案，还是全部塞进原生 ribbon。→ 用户确认：**全部塞进原生 ribbon**；且「插入」要包含 ecology 那 12 项功能。

## 续54: 全部塞进原生 ribbon + 插入 12 项元素（对齐 ecology ecs 扩展控件）

## 续55: 修复 TDZ 崩溃 + 插入 12 项在 React 工具条落地并常驻显示
### ① TDZ 崩溃 `Cannot access 'handleInsertDetailTable' before initialization`
**现象**: 打开设计器即白屏/ErrorBoundary 报 `ReferenceError ... at ExcelDesign.tsx:1129`。
**根因**: `ribbonOptsRef.current = { ..., onInsertDetail: handleInsertDetailTable }`（渲染期直接读取），而 `const handleInsertDetailTable = useCallback(...)` 声明在其后 → const 暂时性死区。
**修复**: 把该 `useCallback` **上移**到 `ribbonOptsRef` 之前（依赖 `message`/`openDetailCanvas` 均更早声明），删除原位置声明。

### ② 插入 12 项「都没有展示出来」
**根因（关键）**: `ExcelRibbon` 渲染被门控 `{nativeRibbonFailed && !nativeRibbonReady && ...}`——原生 ribbon 注册**成功**（`createMenu` 存在、返回 true）→ React 工具条被隐藏；而原生动态注册的菜单项不保证即时渲染 → 用户什么都看不到。
**修复**:
- `ExcelDesign.tsx`：去掉门控，**始终渲染 `ExcelRibbon`**（原生注册保留，仅作状态记录；`nativeRibbonReady/Failed` 注释改为「仅作排障」）。
- `ExcelRibbon.tsx` 补齐 12 项插入（对齐 ecology `excelOperatHead.jsp` 的 `s_insert` 分组）：代码块 / 图片 / 文本 / 链接 / 多语言标签 / Iframe区域 / 公式 / 清除背景 / 标签页 / 说明 / 二维/条形码 / 门户元素。
  - 模块级 `INSERT_DEFS`（`mode: 'element'|'formula'|'action'` + `fields`）：10 项元素走 `grid.insertElement(type, config)`；公式→`insertFormula()`；清除背景→`applyRangeFormat('bg','#ffffff')`。
  - 需要参数的项弹 `Modal` 动态表单（text/textarea/number/select 四种字段，受控 state `insertVals`，非 antd Form 以避免未挂载实例告警）；无参项直接插入并 `message.success`。
  - 插入页同时保留「行列：插入行/列/删除行/列」（`rowColOp`）。
- `ExcelPreview.tsx`：新增模块级 `renderElementNode(meta, displayValue)` 按 `elementType` 渲染（code→pre、image→img、link→a、iframe→iframe、multilang→zh/en/tw、tab→标签 chips、note→带图标、barcode→占位图+内容、portal→占位框），`renderCellNode` 的 `element` 分支改调它。
- 手机端：`MobileItem` 增加 `kind:'element'`；`extractMobileItems` 命中 `cellType==='element'` 直接入列（否则会被当成 title 标题）；`MobileSheetForm` 元素行满宽渲染（无标签列）。
**验证**: lint 0 错误；`tsc --noEmit` 过滤 ExcelDesign/ExcelRibbon/ExcelPreview 无报错。待停 dev server 重启+硬刷新实测：工具条常驻 → 「插入」页 12 项可见，点击弹窗填参 → 活动格写入元素 → 预览按类型渲染。

## 续56: 把 5 个功能集成到原生「开始」菜单之后（原生 ribbon 自定义页签）
**需求**: 「模板/格式/插入/字段属性/明细表」做成原生 Univer ribbon 页签，排在原生「开始」之后（而非独立 React 工具条）。

### ❌ 第一次失败（用 Facade createMenu+appendTo）
- 现象：`createMenu(...).appendTo('ribbon.designerTemplate.others')` 执行无报错、`registered:true`，但 `getMenuByPositionKey('ribbon')` 只返回 4 个原生页签，自定义页签的 `others` 子项**始终没挂上**（`designerTemplate` 只有 `{order,title}`）。
- **根因（关键）**：Facade `FUniver` 内部注入的 `_menuManagerService` 与运行时 UI 插件真实的 `IMenuManagerService` **不是同一实例**（Playwright 实测：`api.createMenu().appendTo('ribbon.designerTest.others')` 写入后 `window.__univerMenuManager._menu.ribbon` 无 `designerTest`）。appendTo 的合并写到了另一个实例 → 原生 ribbon 看不到。
- 同时 `ExcelDesign` 当时把 `ExcelRibbon` 改成「始终渲染」，导致原生页签出来前用户看到两套工具条。

### ✅ 最终方案（直接操作真实实例）
- `UniverExcelGrid.tsx` 暴露 3 个真实实例：`window.__univerMenuManager`(IMenuManagerService)、`window.__univerCommandService`(ICommandService)、`window.__univerLocaleService`(兜底标题)。
- `ribbonRegistry.ts` 重写 `registerDesignerRibbon`：
  - 不再用 Facade；改为 `cmd.registerCommand({id:'designer.cmd.xxx', type:CommandType.COMMAND, handler})` 注册动作命令（用 `cmd.hasCommand` 幂等），再 `mm.mergeMenu({ ribbon: schema })` 一次性合入 5 个页签（order 0.1~0.5 紧排「开始」=0 之后）+ 各页签内分组 + 菜单项（每项 `menuItemFactory` 返回 `type:MenuItemType.BUTTON` 引用对应 commandId）。
  - 实测：`mm.mergeMenu` 给 `designerTemplate` 挂上 `others` 子项后，`getMenuByPositionKey('ribbon')` **立即**包含 `designerTemplate`（证明此实例即渲染所用实例）。
  - 插入类元素项 action 走 `window.__designerOpenInsertModal(type)` 桥接（见下），使其复用 React 弹窗填参；公式/清除背景/行列直接调 `callGrid`。
- `ExcelRibbon.tsx`：新增 `visible` prop；`display:none` 隐藏工具条但**组件仍挂载**（Modal 走 antd Portal 不受影响）。`useEffect` 挂载时把 `window.__designerOpenInsertModal = (type)=>openInsertByType(type)` 挂上（`openInsertByType` 通过 `INSERT_DEFS.find` 找到项再 `openInsert`），卸载时删除。原生插入按钮点击 → 桥接打开 React 参数弹窗。
- `ExcelDesign.tsx`：注册成功（`registerDesignerRibbon` 返回 true）即 `setNativeRibbonReady(true)`，传给 `ExcelRibbon visible={!nativeRibbonReady}`（隐藏 React 工具条，避免双工具条）；10s 内仍失败则保留 React 工具条兜底。
- 必须配 `@univerjs/ui/facade` 别名（config.ts）并 `import '@univerjs/ui/facade'`：否则 `window.__univerFAPI.createMenu` 不存在（但本方案已不依赖它，仅作校验）。

**验证（Playwright 实测，硬刷新后）**：

- 点击原生「插入」页签 → 渲染全部 16 项（12 元素 + 公式 + 清除背景 + 插入行/列/删除行/列）✅
