### 关键技术细节

- **React 初始化顺序**：`useRef(initialValue)` 中的 `initialValue` 不能是同一组件中用 `useCallback` 定义的 function，必须先将 `useCallback` 定义在上方，或者 `useRef` 初始化为 `null`，再用 `useEffect` 同步
- **TypeScript `.d.ts` 文件**：只包含类型声明，枚举值会在编译后被擦除，不能在运行时作为值使用
- **UmiJS `import type`**：`import type { X }` 会被 TypeScript 擦除，但 esbuild（Umi 的构建工具）可能无法正确处理，值导入（不带 `type`）会导致构建错误
- **解决方案**：在 `.tsx` 文件中定义数字常量对象（如 `FIELD_HTML_TYPE = { TEXT: 1, BROWSER: 2, ... } as const`），替代从 `.d.ts` 导入的枚举
