## 需求概述

根据 `泛微E9表单建模字段属性配置详解.md` 文档的标准与规范，对表单建模模块的字段属性功能进行全面优化与改造。

## 核心功能要求

### 1. 后端优化（blade-formmode）

- **扩展 FieldDefinition 实体**：新增缺失字段（textheight、ismand、fieldorder、isused、description、quicktype、impcheck、checkexpression、placeholder、needlog、needefcel、expendattr）
- **新增扩展属性表**：ModeFormFieldExtend（存储字段扩展属性）
- **新增选项配置表**：selectItem（存储选择框/单选/复选的选项数据）
- **优化服务层**：完善 FieldDefinitionServiceImpl，支持扩展属性的 CRUD
- **优化控制器**：新增扩展属性和选项配置的 API 接口

### 2. 前端优化（FormMode/FieldManage）

- **优化字段列表**：新增显示字段属性列（默认值、字段长度、小数位数、是否必填、列表显示等）
- **优化字段表单**：根据泛微E9标准重新设计字段属性配置界面
- 基本属性：字段名称、显示名称、是否必填、是否只读、默认值、排序
- 高级属性：SQL计算字段、字段扩展属性配置
- 校验规则：导入验证类型、验证表达式、提示信息
- **动态字段属性渲染**：根据 fieldHtmlType 和 fieldType 动态显示/隐藏相关属性配置项
- **浏览按钮配置**：支持浏览框类型选择、SQL过滤条件配置
- **选择框选项配置**：支持选项的动态添加/编辑/删除/排序

### 3. 字段类型属性差异支持

- **文本字段（htmltype=1）**：支持字段长度、小数位数、导入验证、验证表达式配置
- **多行文本（htmltype=2）**：支持文本高度配置
- **浏览按钮（htmltype=3）**：支持浏览框类型、扩展属性（sqlwhere、sqlcondition）配置
- **选择框（htmltype=5）**：支持选项配置、选择模式（可选择可新建/只新建/只选择）
- **复选框（htmltype=4）**：支持默认值配置
- **附件上传（htmltype=6）**：支持上传类型配置
- **特殊字段（htmltype=7）**：支持日期/时间选择器配置

## 数据流转要求

- **前后端数据流统一**：前端字段属性配置 → API 提交 → 后端存储 → 数据库表
- **扩展属性存储**：使用 JSON 格式存储到 ModeFormFieldExtend 表
- **选项数据存储**：使用 selectItem 表存储选择框选项
- **字段属性回显**：编辑时正确回显所有属性配置

## 设计规范遵循

- 严格对标泛微E9的属性分类与配置项
- UI 渲染与状态管理遵循 Ant Design Pro 规范
- 数据库存储结构遵循泛微E9的 workflow_billfield 表结构

## 技术栈

- **后端**：Spring Boot 3.5.9 + MyBatis Plus 3.5.19 + MySQL 8.0
- **前端**：React 19 + TypeScript + Ant Design Pro + Umi Max 4
- **状态管理**：React Hooks（useState、useEffect、useMemo）
- **HTTP 请求**：Umi request / useRequest hook
- **样式**：Less + CSS Modules

#### 新增 mode_form_field_extend 表

```sql
CREATE TABLE `mode_form_field_extend` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '主键',
  `fieldid` bigint(20) NOT NULL COMMENT '字段ID',
  `formid` bigint(20) NOT NULL COMMENT '表单ID',
  `expendattr` text DEFAULT NULL COMMENT '扩展属性（JSON格式）',
  `createdate` char(10) DEFAULT NULL COMMENT '创建日期',
  `createtime` char(8) DEFAULT NULL COMMENT '创建时间',
  `modifydate` char(10) DEFAULT NULL COMMENT '修改日期',
  `modifytime` char(8) DEFAULT NULL COMMENT '修改时间',
  PRIMARY KEY (`id`),
  KEY `idx_fieldid` (`fieldid`),
  KEY `idx_formid` (`formid`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='字段扩展属性表';
```

#### 新增 mode_form_field_option 表

```sql
CREATE TABLE `mode_form_field_option` (
  `id` bigint(20) NOT NULL AUTO_INCREMENT COMMENT '主键',
  `fieldid` bigint(20) NOT NULL COMMENT '字段ID',
  `formid` bigint(20) NOT NULL COMMENT '表单ID',
  `optionvalue` varchar(1000) DEFAULT NULL COMMENT '选项值',
  `optionlabel` varchar(1000) DEFAULT NULL COMMENT '选项标签',
  `listorder` int(11) DEFAULT '0' COMMENT '显示顺序',
  `isdefault` int(11) DEFAULT '0' COMMENT '是否默认选中',
  PRIMARY KEY (`id`),
  KEY `idx_fieldid` (`fieldid`),
```

#### 新增 FieldExtend.java 实体

```java
@Data
@TableName("mode_form_field_extend")
@Schema(name = "字段扩展属性")
public class FieldExtend extends Model<FieldExtend> {
    @TableId(value = "id", type = IdType.AUTO)
    private Long id;
    
    @TableField("fieldid")
    private Long fieldId;
    
    @TableField("formid")
    private Long formId;
    
    @TableField("expendattr")
    private String expendattr;
    
    @TableField("createdate")
    private String createDate;
    
    @TableField("createtime")
    private String createTime;
    
    @TableField("modifydate")
    private String modifyDate;
    
    @TableField("modifytime")

}
```

## 性能优化

- **后端**：
- 使用 MyBatis Plus 批量操作减少数据库交互
- 添加数据库索引优化查询性能
- 使用连接池管理数据库连接

- **前端**：
- 使用 React.memo 避免不必要的重新渲染
- 使用 useMemo 和 useCallback 缓存计算结果和函数
- 选项配置使用虚拟滚动（React Window）处理大量数据
- 字段属性配置使用 Tab 分页加载，减少首次渲染压力
