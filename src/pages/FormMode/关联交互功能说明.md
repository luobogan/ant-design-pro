# 表单建模 - 表单管理与字段管理关联交互功能

## 功能概述

实现了表单管理模块与字段管理模块的关联交互功能，支持从表单创建无缝跳转到字段配置，形成完整的表单与字段级联创建闭环。

## 实现的功能

### 1. 表单新增后的"下一步"功能

**文件**: `src/pages/FormMode/FormManage/FormManageAae.tsx`

**实现方式**:
- 在表单新增成功后，显示 `Modal.confirm` 对话框
- 提供两个选项：
  - **"下一步：配置字段"**: 跳转到字段新增页面，并传递新创建表单的 ID
  - **"返回列表"**: 返回表单管理列表页面
- 通过 `formApi.create(data)` 的返回值获取新创建表单的 ID

**代码位置**:
```typescript
// 显示下一步选项
Modal.confirm({
  title: '表单创建成功',
  content: '表单已创建成功，是否立即配置字段？',
  okText: '下一步：配置字段',
  cancelText: '返回列表',
  onOk: () => {
    // 跳转到字段管理的新增页面，并传递表单ID
    navigate(`/formmode/fieldmanage/aae?mode=add&formId=${result.id}`);
  },
  onCancel: () => {
    navigate('/formmode/formmanage');
  },
});
```

### 3. 字段管理页面接收表单 ID 并自动选择

**文件**: `src/pages/FormMode/FieldManage/FieldManage.tsx`

**实现方式**:
- 从 URL 参数中获取 `formId`（通过 `useSearchParams` hook）
- 在组件初始化时，将 `selectedFormId` 状态初始化为 URL 中的 `formId`
- 在 `fetchFormList` 函数中，优先选择 URL 中指定的表单
- 如果 URL 中的 `formId` 在表单列表中不存在，则选择第一个表单

**代码位置**:
```typescript
// 从 URL 获取 formId
const [searchParams] = useSearchParams();
const urlFormId = searchParams.get('formId');

// 初始化状态
const [selectedFormId, setSelectedFormId] = useState<string>(urlFormId || '');

// 获取表单列表时，优先选择 URL 中指定的表单
const fetchFormList = async () => {
  try {
    const result = await formApi.getAll();
    setFormList(result || []);
    
    // 如果 URL 中有 formId，优先选择该表单
    if (urlFormId && result && result.length > 0) {
      const targetForm = result.find((form: FormDefinition) => form.id === urlFormId);
      if (targetForm) {
        setSelectedFormId(urlFormId);
        return;
      }
    }
    
    // 如果没有选中表单，默认选择第一个
    if (result && result.length > 0 && !selectedFormId) {
      setSelectedFormId(result[0].id);
    }
  } catch (error) {
    console.error('获取表单列表失败:', error);
  }
};
```

### 4. 字段新增页面接收表单 ID

**文件**: `src/pages/FormMode/FieldManage/FieldAdd.tsx`

**实现方式**:
- 从 URL 参数中获取 `formId`（通过 `useSearchParams` hook）
- 在提交表单时，将 `formId` 传递给 `fieldApi.create()` 方法
- 提交成功后，返回字段管理列表页面，并传递表单 ID

**代码位置**:
```typescript
// 从 URL 获取 formId
const [searchParams] = useSearchParams();
const formId = searchParams.get('formId');

// 提交表单时使用 formId
const handleSubmit = async (values: FieldDefinitionFormData) => {
  if (!formId) {
    message.error('表单ID不能为空');
    return;
  }

  setLoading(true);
  try {
    await fieldApi.create({
      ...values,
      formId,
    });
    message.success('新增成功');
    // 返回字段管理列表，并传递表单ID
    navigate(`/formmode/fieldmanage?formId=${formId}`);
  } catch (error) {
    console.error('新增失败:', error);
    message.error('新增失败');
  } finally {
    setLoading(false);
  }
};
```

## 交互流程

### 流程一：新增表单后配置字段

1. 用户进入 **表单管理列表页面** (`/formmode/formmanage`)
2. 点击 **"新增"** 按钮，进入表单新增页面 (`/formmode/formmanage/aae?mode=add`)
3. 填写表单信息（表单名称、数据库表名等）
4. 点击 **"保存"** 按钮，提交表单
5. 表单创建成功后，显示确认对话框：
   - 点击 **"下一步：配置字段"** → 跳转到字段新增页面 (`/formmode/fieldmanage/aae?mode=add&formId=xxx`)
   - 点击 **"返回列表"** → 返回表单管理列表页面
6. 在字段新增页面，配置字段信息
7. 点击 **"保存"** 按钮，提交字段
8. 字段创建成功后，返回字段管理列表页面 (`/formmode/fieldmanage?formId=xxx`)

### 流程二：编辑表单后管理字段

1. 用户在 **表单管理列表页面** (`/formmode/formmanage`)，点击某个表单的 **"编辑"** 按钮
2. 进入表单编辑页面 (`/formmode/formmanage/aae?mode=edit&id=xxx`)
3. 修改表单信息
4. 可以点击 **"管理字段"** 按钮，跳转到字段管理列表页面 (`/formmode/fieldmanage?formId=xxx`)
5. 在字段管理列表页面，可以查看、新增、编辑、删除该表单的字段

## 技术要点

### 1. 数据传递

- 使用 **URL 参数** 传递表单 ID (`formId`)
- 在页面之间跳转时，通过 URL 参数保持数据状态
- 例如：`/formmode/fieldmanage/aae?mode=add&formId=123`

### 2. 状态管理

- 使用 `useState` 管理表单选择状态 (`selectedFormId`)
- 使用 `useEffect` 监听 `selectedFormId` 变化，自动加载字段列表
- 使用 `useSearchParams` 获取 URL 参数

### 3. 用户体验

- 表单创建成功后，提供明确的下一步操作指引
- 编辑表单时，可以快速跳转到字段管理页面
- 字段管理页面自动选择对应的表单，无需手动选择

## 注意事项

1. **后端 API 需要实现**:
   - `formApi.create(data)` 需要返回创建成功的表单对象，包含 `id` 字段
   - `formApi.getAll()` 需要返回所有表单的列表
   - `fieldApi.create(data)` 需要接收 `formId` 参数

2. **路由配置**:
   - 确保动态路由配置正确，能够匹配 `/formmode/formmanage/aae`、`/formmode/fieldmanage/aae` 等路径
   - 路由配置在后端数据库中，需要添加相应的菜单和按钮权限

3. **TypeScript 类型定义**:
   - 确保 `FormDefinition` 接口包含 `id` 字段
   - 确保 `FormDefinitionFormData` 接口可以传递 `formId` 参数
