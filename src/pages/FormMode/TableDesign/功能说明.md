# 低代码表设计器 - 功能说明

## 功能概述

低代码表设计器是一个可视化的数据库表和字段配置工具，支持通过界面配置生成数据库表结构和表单JSON定义。

## 核心功能

### 1. 表配置 (Tab 1)
- **表单名称**: 表单的显示名称
- **数据库表名**: 对应的数据库表名
- **描述**: 表单描述信息
- **状态**: 启用/禁用切换

### 2. 字段配置 (Tab 2)
- **添加字段**: 点击"添加字段"按钮新增字段
- **字段排序**: 每个字段卡片右上角有上移/下移按钮，可调整字段顺序
- **字段属性**:
  - 字段名称 (fieldName): 数据库字段名
  - 字段标签 (fieldLabel): 显示标签
  - 字段HTML类型 (fieldHtmlType): 1-文本字段, 2-浏览按钮, 3-选择框, 4-附件上传, 5-特殊字段, 6-复选框
  - 字段类型 (fieldType): 详细类型（如单行文本、多行文本、下拉框等）
  - 数据库类型 (fieldDbType): 自动根据字段类型设置
  - 字段长度 (fieldLength): 数据库字段长度
  - 是否必填 (isRequired): 开关控制
  - 是否只读 (isReadOnly): 开关控制
- **删除字段**: 点击删除按钮可删除字段

### 3. SQL 预览 (Tab 3)
- 点击"生成 SQL"按钮，根据表配置和字段配置生成 CREATE TABLE SQL 语句
- 包含主键 id、创建时间、更新时间等标准字段
- 支持字段类型、长度、是否必填、默认值、注释等属性

### 4. 表单 JSON (Tab 4)
- 点击"生成表单 JSON"按钮，生成表单结构定义的 JSON
- 包含表单名称、表名、描述、字段列表等信息
- 可用于表单渲染和配置

### 5. 保存
- 点击"保存"按钮，先保存表单定义，再批量保存字段定义
- 支持新增和编辑模式

### 6. 导出
- 点击"导出"按钮，导出完整的表设计数据为 JSON 文件
- 包含表配置、字段配置、SQL 预览、表单 JSON 等信息

## 技术实现

### 字段排序
- 使用 `handleMoveField(fromIndex, toIndex)` 函数实现字段排序
- 每个字段卡片右上角有上移/下移按钮
- 第一个字段禁用上移按钮，最后一个字段禁用下移按钮
- 排序后自动更新所有字段的 `sort` 属性

### 数据库类型自动设置
- 根据 `fieldHtmlType` 和 `fieldType` 自动设置 `fieldDbType`
- 例如：文本字段 → varchar，数字字段 → int，日期字段 → date

### 数据持久化
- 保存时先调用 `formApi.create()` 或 `formApi.update()` 保存表单定义
- 然后遍历字段列表，逐个调用 `fieldApi.create()` 或 `fieldApi.update()` 保存字段定义

## 使用流程

1. 在"表配置"Tab 中填写表单名称和数据库表名
2. 切换到"字段配置"Tab，点击"添加字段"添加所需字段
3. 为每个字段配置属性（名称、标签、类型等）
4. 使用上移/下移按钮调整字段顺序
5. 切换到"SQL 预览"Tab，点击"生成 SQL"预览建表语句
6. 切换到"表单 JSON"Tab，点击"生成表单 JSON"预览表单定义
7. 点击"保存"按钮保存设计
8. （可选）点击"导出"按钮导出设计为 JSON 文件

## 后续优化方向

1. **拖拽排序**: 集成 @dnd-kit/sortable 实现真正的拖拽排序（当前使用上移/下移按钮）
2. **字段模板**: 支持从模板快速添加常用字段（如创建时间、创建人等）
3. **批量编辑**: 支持批量修改字段属性
4. **字段关联**: 支持配置字段间的关联关系
5. **导入功能**: 支持从已有数据库表导入字段定义
6. **预览增强**: 实时预览表单渲染效果
