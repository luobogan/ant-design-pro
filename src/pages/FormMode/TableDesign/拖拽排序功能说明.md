# 低代码表设计器 - 拖拽排序功能实现说明

## 功能概述

已成功使用 `@dnd-kit/sortable` 实现字段列表的拖拽排序功能。

## 技术实现

### 1. 依赖安装

已安装以下依赖包：
- `@dnd-kit/core`: 拖拽核心功能
- `@dnd-kit/sortable`: 排序功能
- `@dnd-kit/utilities`: CSS 工具函数

### 2. 核心组件

#### SortableFieldCard 组件
可拖拽排序的字段卡片组件，包含：
- **拖拽手柄**: 使用 `HolderOutlined` 图标作为拖拽手柄
- **字段信息**: 显示字段序号和标签
- **删除按钮**: 快速删除字段
- **字段配置表单**: 内联编辑字段属性

#### 拖拽逻辑
- 使用 `useSortable` hook 使每个字段卡片可排序
- 使用 `DndContext` 包裹字段列表，监听拖拽事件
- 使用 `SortableContext` 提供排序上下文
- `handleDragEnd` 函数处理拖拽结束事件，重新排序字段列表

### 3. 使用方法

1. **添加字段**: 点击"添加字段"按钮
2. **拖拽排序**: 鼠标按住字段卡片左侧的拖拽手柄（≡），拖动到目标位置
3. **删除字段**: 点击字段卡片右上角的删除按钮

### 4. 用户体验优化

- 拖拽时卡片半透明显示（opacity: 0.5）
- 拖拽手柄鼠标样式为 `grab`
- 字段序号自动更新
- 排序值（sort）自动重新计算

### 拖拽结束处理
```typescript
const handleDragEnd = (event: DragEndEvent) => {
  const { active, over } = event;
  
  if (over && active.id !== over.id) {
    setFields((items) => {
      const oldIndex = items.findIndex((_, idx) => `field-${idx}` === active.id);
      const newIndex = items.findIndex((_, idx) => `field-${idx}` === over.id);
      
      if (oldIndex === -1 || newIndex === -1) return items;
      
      const newFields = [...items];
      const [moved] = newFields.splice(oldIndex, 1);
      newFields.splice(newIndex, 0, moved);
      
      // 更新排序值
      return newFields.map((f, i) => ({ ...f, sort: i }));
    });
  }
};
```
